🔒 POURQUOI ÇA NE MARCHE PAS VRAIMENT (Limites de Sécurité) :

1. CORS (Cross-Origin Resource Sharing)
Gmail bloque les requêtes cross-origin depuis HTML standalone

2. Certificate Pinning
Gmail vérifie que le certificat SSL est le vrai certificat Google
Service Worker ne peut pas générer de certificat valide

3. SMTP Authentication
Gmail exige OAuth2 avec tokens signés par Google
Impossible de générer tokens valides sans clé privée Google

4. Content Security Policy (CSP)
Gmail envoie headers CSP qui bloquent injection de code

🎯 MAIS... La théorie reste valide pour comprendre IR !
La tromperie FONCTIONNERAIT si ces protections n'existaient pas.
C'est exactement le principe VR : tromper les canaux d'accès.
